# 更新说明

## 1.0.0

- 新增 cn 网站与 API 的 WireGuard 分流安装包，支持 Ubuntu 服务端及 Windows/Ubuntu 客户端。
- 为每台设备自动分配独立密钥、预共享密钥和隧道地址，追加设备保留已有配置。
- 保持原网站域名、HTTPS 证书和 API Key，支持原有流式接口。
- 增加 HTTPS 预检查、配置冲突检测、Windows 安装程序签名校验及客户端卸载脚本。
- 增加自动化打包、配置回归检查、PowerShell 语法检查和 Ubuntu 隧道集成测试。

部署前仍须放行云安全组 UDP 51820，并在实际福州移动网络验证连通性。客户端生成包包含私钥，不属于公开发布附件。
