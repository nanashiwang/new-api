## 1. 5 分钟快速开始

如果你只是想先跑通一次调用，按下面流程走即可。

### 1.1 注册账号

1. 打开 `https://cn.meta-api.vip/`。
2. 点击注册，填写邮箱并完成验证码。
3. 如页面出现 Turnstile 人机校验，先完成校验再提交。
4. 如果你通过邀请链接进入，确认注册链接中包含 `aff` 参数。

### 1.2 创建令牌

1. 进入 `控制台 -> 令牌管理`。
2. 点击新建令牌。
3. 新手建议先使用默认分组或管理员建议的分组。
4. 保存后复制 API 密钥，格式通常是 `sk-...`。
5. 点击令牌旁边的测试，确认令牌可用。

### 1.3 跑通第一条请求

把下面命令里的 `sk-xxxx` 替换成你的 API 密钥，模型名以模型广场为准：

```bash
curl https://cn.meta-api.vip/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "你好"
      }
    ]
  }'
```

看到模型返回内容，就说明注册、令牌、余额、分组和接口地址基本都正常。

## 适用对象

- 普通用户：注册账号、充值订阅、创建 API 令牌、查看日志、申请明细账单或发票。
- 管理员：处理用户、渠道、模型、订阅、订单、明细账单和发票审核。
- 开发者：按 OpenAI 兼容格式接入平台 API。

## 2. 注册与登录

1. 访问平台首页，点击注册或登录。
2. 注册时填写邮箱并完成验证码验证。
3. 页面出现 Turnstile 人机校验时，需要先完成校验再提交。
4. 如果使用邀请链接进入注册页，系统会自动绑定邀请关系。

常见问题：

- 收不到验证码：先检查垃圾箱、邮箱地址是否填写正确，再联系管理员排查邮件服务。
- 注册失败：刷新页面后重新完成人机校验，避免重复提交旧的校验 token。
- 邀请关系未绑定：确认注册链接中包含 `aff` 参数，并在同一页面完成注册。

## 3. 创建 API 令牌

1. 进入 `控制台 -> 令牌管理`。
2. 点击新建令牌。
3. 按需设置名称、额度、过期时间、分组或模型权限。
4. 保存后复制令牌，妥善保管，不要公开发送给他人。

令牌用于接口请求：

```http
Authorization: Bearer <你的令牌>
```

如果调用失败，优先在令牌管理中使用测试功能确认令牌是否可用。

## 4. 调用接口

API 地址以控制台首页 `API 信息` 展示为准。示例：

```bash
curl https://cn.meta-api.vip/v1/chat/completions \
  -H "Authorization: Bearer sk-xxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.5",
    "messages": [
      {
        "role": "user",
        "content": "你好"
      }
    ]
  }'
```

常用接口：

| 能力 | 接口 |
|------|------|
| 聊天补全 | `POST /v1/chat/completions` |
| Responses | `POST /v1/responses` |
| 图片生成 | `POST /v1/images/generations` |
| 图片编辑 | `POST /v1/images/edits` |
| 模型列表 | `GET /v1/models` |

客户端工具接入请看：[NAN 客户端接入与聊天快捷配置](./NAN_CLIENTS.md)。

如果已经出现报错，优先看：[NAN 常见报错排查](./NAN_TROUBLESHOOTING.md)。

## 5. 充值与订阅

1. 进入 `控制台 -> 钱包管理`。
2. 根据需要选择额度充值或订阅套餐。
3. 支付完成后等待系统自动到账。
4. 如长时间未到账，准备好订单号、支付时间、支付金额并联系管理员处理。

说明：

- 订阅套餐通常包含有效期、额度规则、购买上限和适用分组。
- 钱包余额和订阅额度的扣费优先级以页面配置为准。
- 使用日志中的消耗金额用于排查调用成本，实际账单以平台记录为准。

## 6. 明细账单与发票申请

1. 进入 `控制台 -> 钱包管理 -> 账单`。
2. 在账单或发票相关入口中选择可申请的已支付订单。
3. 根据需要选择普通发票或专用发票，并填写对应信息。
4. 提交后等待管理员审核。
5. 审核通过后，平台可通过邮件发送发票 PDF 和明细账单 PDF。

申请规则：

- 仅支持已支付成功的订单。
- 已在审核中或已开具的订单不可重复选择。
- 被驳回的订单可重新提交申请。
- 专用发票的单位名称和税号必填，注册地址、注册电话、开户银行、银行账号为选填。

## 7. 查看调用日志

1. 进入 `控制台 -> 使用日志`。
2. 按时间、模型、令牌、渠道或请求状态筛选。
3. 排查失败时重点查看错误信息、请求时间、模型名和令牌。

建议排查顺序：

1. 确认账户余额或订阅额度是否充足。
2. 确认令牌没有过期或被禁用。
3. 确认调用模型在当前分组中可用。
4. 确认请求体格式符合接口要求。
5. 如果是上游超时或断流，记录请求时间后联系管理员查看渠道日志。


## 8. 费用与扣费说明

新手理解成本时，重点看这几个概念：

| 概念 | 说明 | 在哪里看 |
|------|------|----------|
| 账户余额 | 钱包里的可用额度 | `控制台 -> 数据看板` 或 `钱包管理` |
| 订阅套餐 | 按有效期、每日额度、分组规则提供额度 | `钱包管理 -> 订阅套餐` |
| 模型价格 | 不同模型和分组的计费倍率不同 | `模型广场` |
| 使用日志 | 每次请求的模型、消耗、状态和错误 | `控制台 -> 使用日志` |
| 支付记录 | 充值、订阅、订单和申请记录 | `钱包管理 -> 账单` |

排查扣费问题建议顺序：

1. 先看 `使用日志`，确认是哪一次请求产生消耗。
2. 再看模型名和分组，确认是否调用了高价模型。
3. 如果请求失败但仍有消耗，记录请求时间、模型名、令牌和错误信息联系管理员。
4. 如果充值未到账，准备订单号、支付时间和支付金额。

## 9. 安全提醒

API 密钥等同于账户调用权限，建议按下面规则使用：

- 不要把 API 密钥发到群里、截图里、公开仓库里。
- 共享截图时遮住 `sk-...`、邮箱、订单号等敏感信息。
- 不要把带 `{key}` 的聊天链接配置到不可信第三方网站。
- OpenClaw 会启动本地网关，不要把本地端口暴露到公网。
- 如果怀疑 API 密钥泄露，立即禁用旧令牌并创建新令牌。
- 给不同客户端创建不同令牌，后续排查和禁用更方便。

## 10. 管理员常用操作

| 模块 | 用途 |
|------|------|
| 用户管理 | 查看用户状态、余额、分组、邀请关系和异常账号 |
| 渠道管理 | 配置上游地址、密钥、分组、模型和健康状态 |
| 模型管理 | 管理模型展示、倍率、分组和可用性 |
| 订阅管理 | 配置套餐价格、有效期、额度和购买限制 |
| 兑换码管理 | 创建和管理余额、套餐等兑换码 |
| 系统设置 | 配置公告、邮件、支付、人机校验和其他系统参数 |
| 钱包 / 发票审核 | 查看订单、处理明细账单和发票申请 |
