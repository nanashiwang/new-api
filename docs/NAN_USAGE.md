## 1. 5 分钟快速开始

### 1.1 注册账号

1. 打开 `https://cn.meta-api.vip/`。
2. 点击注册，填写邮箱验证码。
3. 如果有邀请链接，使用完整链接注册，例如 `/register?aff=xxxx`。
4. 出现 Turnstile 校验时，完成校验后再提交，不要重复点击。

### 1.2 创建 API 令牌

1. 进入 `控制台 -> 令牌管理`。
2. 点击新建令牌。
3. 按目标模型选择分组：

| 用途                | 分组建议                              |
| ------------------- | ------------------------------------- |
| Codex / OpenAI 模型 | `vip` / `svip` / 土豪分组 |
| Claude 模型         | `claude`                              |
| Gemini 模型         | `gemini`                              |

![令牌管理入口和关键字段](./images/nan-token-management-overview.png)

4. 复制完整 API Key，通常以 `sk-` 开头。

### 1.3 跑通第一条请求

```bash
curl https://cn.meta-api.vip/v1/chat/completions \
  -H "Authorization: Bearer sk-你的API密钥" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.3-codex",
    "messages": [{"role":"user","content":"hello"}]
  }'
```

如果返回 401，先检查 API Key 是否复制完整；如果返回模型不可用，先检查令牌分组和模型名称。

## 2. 钱包与账单

### 2.1 充值与订阅

入口：`控制台 -> 钱包管理`。

| 功能     | 说明                         |
| -------- | ---------------------------- |
| 额度充值 | 按金额充值到账户余额         |
| 订阅套餐 | 购买月卡/日卡等套餐          |
| 账单     | 查看充值、订阅、钱包购买订单 |
| 邀请奖励 | 查看返佣、提现和划转         |

### 2.2 明细账单与发票申请

入口：`钱包管理 -> 账单 -> 发票`。

规则：

- 只能选择支付成功的订单。
- 申请中、已开具的订单不可重复选择。
- 驳回后订单会释放，可以重新申请。
- 支持普票和专票；专票的单位名称、税号必填。
- 管理员可在详情中查看订单信息、打印明细账单、上传 PDF 并发送邮件附件。

## 3. 日志与排查

### 3.1 看调用日志

入口：`控制台 -> 使用日志`。

重点看：

- 请求时间。
- 令牌名称。
- 模型名。
- 消耗金额/额度。
- 错误文本。
- 请求是否流式。

### 3.2 常用判断

| 现象                | 优先检查                                      |
| ------------------- | --------------------------------------------- |
| 401 / unauthorized  | Key 是否完整、令牌是否启用、环境变量是否生效  |
| model not found     | 模型名和分组是否匹配                          |
| 余额不足            | 钱包余额、订阅额度、令牌额度限制              |
| stream disconnected | 记录时间、模型、请求 ID，联系管理员查上游日志 |
| 充值未到账          | 提供订单号、支付时间、支付金额                |

更多见 [常见报错排查](./NAN_TROUBLESHOOTING.md)。

## 4. 管理员操作

| 入口       | 用途                               |
| ---------- | ---------------------------------- |
| 用户管理   | 查用户、额度、分组、邀请关系       |
| 渠道管理   | 查渠道状态、测试渠道、禁用异常渠道 |
| 模型管理   | 配置模型可见性和分组               |
| 订阅管理   | 管理套餐价格、额度、有效期         |
| 兑换码管理 | 创建兑换码和配置权益               |
| 系统设置   | 文档地址、导航、支付、日志、监控等 |
| 钱包账单   | 审核发票/明细账单申请              |

## 5. 对外说明模板

给用户排查问题时，建议一次性让对方提供：

```text
账号邮箱/用户ID：
问题发生时间：
使用客户端：Codex / Claude Code / Gemini / OpenCode / OpenClaw / API
模型名：
令牌名称：
完整错误文本：
是否流式请求：是/否
```

不要让用户直接发完整 API Key。
