# Agent Note: K3 用户体验实测与真实响应本地回放

Status: implemented

## Problem

缓存与思考字段的本地回归通过，不能证明元衡线上入口返回了客户需要的信息。用户提供测试令牌并授权按真实用户体验测试、不设费用上限；这不授权修改生产配置、部署或无意义压测。

## Existing capabilities and related decisions

- [用量字段保真](../../implemented/bug-fix/2026-09-29-kimi-usage-field-preservation.md)覆盖本地归一、转发和隔离结算，本轮沿用其未知值和计费边界。
- [官方 KVV 对齐](../../implemented/testing/2026-09-29-official-kvv-alignment.md)部分重叠：复用用例语义，不修改官方断言，不把补充探针称为完整官方验收。
- [真实入口验收记录](../../implemented/testing/2026-09-29-kimi-live-acceptance.md)部分重叠：该文件为已有独立工作，保持原样。本轮聚焦截图涉及的用量字段和普通用户路径，再将合成响应送入本地代码回放，不接管其渠道与完整性能验收。
- 入口复用普通令牌鉴权、模型列表和令牌用量查询；本地复用既有 relay handler 与隔离数据库测试，不启动连接生产数据库的应用。

## Decision

- 先只读核对元衡入口、模型访问及令牌用量；令牌仅保留在本轮进程内存，不存代码、报告或命令行，测试后清空并重置内存会话。
- 使用合成问题，串行检查流式/非流式、low/high/max、相同长前缀重复请求、工具结果回环；根据实际失败缩小后续范围，不自动重试，不修改默认分组或路由。
- 保存请求编号、HTTP状态、实际内容/思考首字时间、完整终态与原始 usage；心跳不算首字，字段存在不等于缓存命中。
- 将合成响应的必要字段作为无密钥本地夹具，复用修改后的 handler 验证字段保留与未报告字段不造数。线上体验与本地回放结论分别报告。
- 不为测试关闭生产重试；客户端无自动重试，服务端是否重试在没有日志证据时标未知。
- 对紧急来源定位，从NAN服务器按现有渠道配置直连供应商，再以管理员密钥的既有单次请求指定渠道能力经过元衡验证；不改全站路由。供应商凭据留在远端进程内存，直接请求与元衡请求分别记账，不伪称同一响应的双路抓包。
- 实测同渠道首次响应报告 `cache_read_tokens=0`，重复请求同时报告 `cache_read_tokens=cached_tokens=prompt_tokens_details.cached_tokens=5720`、`prompt_tokens=5720`。补充本地漏掉的 `cache_read_tokens` 后备来源，只在既有来源缺失时读取；不映射 `cache_write_tokens` 为读取量，不扩大到其他模型或协议。用实际用量切片与隔离结算覆盖明确零、命中、未知及冲突。

## Alternatives considered

- **直接部署后测试**：最接近最终效果，但用户当前授权的是本地修改与体验实测；保留部署边界，通过回放验证本地补丁。
- **直接执行完整官方套件/压测**：覆盖面更广，但耗时、噪声及负载更高，且不能替代截图字段缺失的来源定位。先运行有限的普通用户用例，未测范围明确列出。
- **只看生产汇总日志**：没有新增模型消费，却无法观察原始字段路径与可验证内容；只作必要的补充，不替代实测。

- 实际usage切片重建的16个JSON/SSE/force-format子用例通过；新增回归先复现明确缓存零没有兼容别名，再修复。
- 隔离SQLite覆盖6种用量形状、流式/非流式，钱包、令牌及日志扣费一致；未知、冲突、非法或过大数字、缓存写入不误当读取均有回归。
- 全仓 `go test -p 2 -timeout 120s ./...` 通过；controller/OpenAI handler 的Kimi、流式完整性、失败退款定向race检查重复2次通过。
- 在线模型请求完成后才启动Go检查，所有启动的测试会话均取得退出结果；未启动应用服务器、SSH会话或长期测试服务。build、verify-notes、diff检查通过，末次进程检查没有Go构建/测试残留，本轮遗留测试进程为0。

## Consequences

真实样本发现并补齐了原有离线夹具未覆盖的字段，但只覆盖本次选例，不能替代完整官方KVV、供应商原始响应对照、长上下文或性能压测。同分组可能路由到不同供应商，相同前缀不保证同缓存池；缺少供应商原始响应时，只报告元衡客户端边界，不推定缺字段发生在供应商还是网关。线上实测和本地回放分开记录，保留部署后的验证工作。
