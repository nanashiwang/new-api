# Agent Note: 令牌管理的可读列表与操作隔离

Status: implemented

## Problem

令牌表格十五列与重复操作按钮使名称、额度和复制难找。列表返回脱敏key，但当前批量复制弹窗直接拼接该值，可能复制出不可用密钥。列表请求异常缺少可靠收尾；编辑保存晚返回可能关闭新打开的表单。

## Decision

复用既有列渲染、状态、分组倍率与额度语义；默认列表合并名称/密钥、额度和分组，完整模型/IP/运行限制与时间保留在可展开详情，限制配置在主行有明确提示。保留完整表格切换，不改接口和权限。手机显示可操作摘要及详情，批量选择显式受控并在新查询开始时清除。

批量复制只在用户明确点击后通过已有/key接口取得完整密钥，失败不复制半份或脱敏值；关闭弹窗使旧请求失效。账户切换重挂载列表，不保留完整密钥。列表失败保留明确重试、不伪装空结果，刷新时沿用已应用筛选。编辑/创建保存按会话序号隔离，旧结果不能关闭新表单或清除新输入，不能撤销已发送请求。

参考已登录AIHubMix列表和创建抽屉的轻边框、标题/工具栏、双层信息；元衡已有宽创建分组选组保持，避免重新设计权限表单。

## Alternatives considered

- 仅缩小字体可以减少宽度，但十五列仍难扫读；摘要与可展开详情保留全部信息。
- 批量复制复用列表key最简单，但脱敏值不可用于调用；复用已有授权取key接口。
- 保存时禁止关闭可避免部分竞态，却限制使用且仍不能解决身份切换；按会话使晚响应失效。

## Verification

本地实际页面使用合成API验证：列表和搜索失败不显示旧操作，重试保留原条件/目标页；输入未查询关键词后翻页仍使用已应用搜索。受控选择翻页清空；单条及两条批量复制得到完整fixture密钥而非脱敏字段，原有sk前缀不重复。

编辑不改保存保留组、无限额度、模型限制、IP、并发与有效期；保存失败保留输入可重试。人工挂起旧令牌保存，关闭并打开另一条，再释放旧请求，新表单仍打开且内容未变。隔离创建确认所选分组与原默认限制，不发真实模型请求。桌面摘要/详情、完整列切换、390/320px与暗色验收，窄屏操作默认展开；已有聊天配置异常从渲染时提示移到实际点击时提示，避免逐行刷屏。

新增token-copy回归覆盖真实key按需读取、前缀规范、失败不返回部分内容、取消不继续读取；既有分组/收藏与17语言回归。同步主线模型能力兼容版98后，42项复制/分组/收藏/17语言/模型能力回归、修改源码ESLint/Prettier、主站Vite构建及笔记校验通过；保留既有大包提示。保存会话与列表异常为隔离API手动验收，未使用生产令牌。

## Consequences

限制折叠但主行保留标记，展开显示完整配置；完整表格可切回。取消只阻止前端后续动作，不撤销已发送的服务端保存；取消批量创建仅停止尚未发送的下一条。共享CardPro新增默认关闭的手机操作初始展开选项，仅令牌页启用，其他页面行为保持。

列表完整密钥仅存在当前身份的内存缓存，账户切换重新挂载；不写本地存储、不回显到成功通知。复制失败保留有界可选择文字；不读取生产密钥、不上传或调用外部服务。没有后端、计费、权限或数据库变化；用户随后授权以远端为准同步、提交并合并main；不执行生产部署。临时预览与测试页面在验收后关闭，本轮遗留测试进程为零。
